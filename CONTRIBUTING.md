# Contributing

## Setup

```sh
mise trust && mise install
mise exec -- lefthook install   # git hooks
mise run check                  # formatting, lint, Lua and Go tests, types, luac
mise run cli:build              # bin/amber
```

## Tasks

| Task | What it does |
| --- | --- |
| `mise run fmt` | Formats Lua, shell, and Go. |
| `mise run test` | Lua tests. They stub Rex and Git. |
| `mise run cli:test` | Go tests. They use real Git repositories in temporary directories and a fake Rex server; Rex is not required. |
| `mise run cli:run -- <args>` | Runs the command from source. |
| `mise run cli:go -- <args>` | Runs any `go` command in `cli/`. |
| `mise run cli:dist` | Builds the release binaries locally into `dist/`. |

## Heavier tests

These are not part of `check`:

- `mise run e2e` starts a scratch Rex server with local Git origins in place of GitHub and drives the real `bin/amber` through install, build, update, restore, clean, doctor, and the floating window. It needs `rex` and touches nothing of yours.
- `mise run brew:local` builds the formula from `HEAD`, installs it through a throwaway tap, runs the end-to-end test against the installed library, and removes everything it added. `-- --fetch-only` skips the install, which otherwise builds with Homebrew's `go`.

## Releasing

Push a `vX.Y.Z` tag that matches `version` in `amber.lua`. The release workflow publishes binaries for macOS and Linux on arm64 and x86-64 plus a source archive, then commits the matching `Formula/amber-rex.rb` to `main`. The formula is generated by `scripts/formula.sh`; do not edit it by hand.

See [docs/architecture.md](docs/architecture.md) for how the pieces fit together.
